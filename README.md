# Car Diagnostic System

برنامج Windows لتشخيص أعطال السيارات متعددة الماركات من خلال واجهات اتصال VCI/OBD، مع تطوير تدريجي مبني على التوافق الفعلي بين السيارة ووحدة التحكم وجهاز الاتصال والتعريفات المتاحة.

> **تنبيه نطاق:** هذا المشروع ليس نظام إدارة ورشة أو عملاء أو فواتير أو مخزون. ولا يدّعي أن كل وظيفة متاحة لكل سيارة.

## الأهداف الرئيسية
- قراءة VIN عند دعم السيارة والواجهة.
- فحص وحدات التحكم المدعومة وعرض نتيجة Full System Scan.
- قراءة أكواد الأعطال DTC وحالتها ومسحها عند السماح.
- عرض Live Data وFreeze Frame.
- إضافة Service Functions ثم Active Tests وCoding/Adaptation بعد استكمال متطلبات الأمان والتغطية.
- التكامل مع حلول OEM المصرح بها لعمليات البرمجة؛ لا ينفذ المشروع برمجة ECU عامة أو غير موثقة.
- تقارير قابلة للحفظ والطباعة، وواجهتان عربية وإنجليزية.

## التقنية المبدئية
- C# وWPF وMVVM.
- .NET: يثبت الإصدار المستهدف بعد التحقق من دعم Microsoft وتوافق الحزم وبيئة التشغيل وقت بدء التنفيذ.
- SQLite لبيانات التطبيق المحلية والتعريفات الموزعة.
- LiveCharts2 للرسوم البيانية عند الحاجة.
- اختبارات آلية وMock VCI/Vehicle لتطوير المكونات دون سيارة فعلية.

## تقسيم المسؤوليات

- **Developer C:** تطبيق Windows وتجربة المستخدم والتقارير.

## حالة المشروع
المستودع في مرحلة التأسيس. وجود مجلد أو واجهة لا يعني أن وظيفة التشخيص مكتملة أو مختبرة على مركبة حقيقية. راجع سجل المهام والاختبارات قبل اعتبار أي ميزة جاهزة.

## الأمان والامتثال
- لا ترسل أوامر غير موثقة إلى وحدات التحكم.
- لا تنفذ Active Tests أو Coding أو Programming في المرحلة الأولى.
- لا تتجاوز أنظمة الحماية أو المصادقة أو قيود الشركات المصنعة.
- استخدم بيانات ومكتبات وفق تراخيصها، ووثق المصدر والترخيص.
- أي عملية قد تؤثر على سلامة المركبة تتطلب تحققًا من التوافق، وتحذيرًا واضحًا، وموافقة صريحة، وشروط تشغيل آمنة.
